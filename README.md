# Nixie-Tube-Clock-and-Divergence-Meter
Programmable Nixie tube clock around an ATmega328P, integrating an 8-digit multiplexed display, K155ID1 BCD decoder, DS3231SN real-time clock, USB-UART interface, and high-voltage Nixie tube circuitry. Built-in Divergence meter mode (randomization sequence), anti-cathode poisoning routine, and timekeeping after shutoff via a CR2032 coin cell.
